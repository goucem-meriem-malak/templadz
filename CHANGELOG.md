# Changelog

## 0.2.0
- Full workspace: menu bar (File/Edit/View/Insert/Format/Tools/Help), formatting ribbon, global keyboard shortcuts, status bar (page X of Y, word count, language, view modes, zoom 50–200%).
- Editor: fonts, sizes, colors, highlight, underline/strike, alignment, line spacing, lists, tables, images, horizontal line, page break, header/footer, per-paragraph LTR/RTL, find & replace.
- Fill: single-copy form plus quick-batch bracket syntax (`fname[a; b] bday[21/11/2001]`) and CSV batch; export PDF and DOCX with distinct file names.
- Activation simplified: any code starting with `TEMPLADZ` (placeholder, not real protection). Key-generation tool removed.
- New `.tpz` file logo and icon; monochrome gray theme with light/dark modes; EN/FR/AR with RTL.
- Docs: README, SETUP, DOCUMENTATION, SECURITY_CHECKLIST, legal drafts (EN/FR/AR).

## 0.1.0
- Electron + React + Tiptap prototype: basic editor, fields, fill form, CSV batch to PDF, `.tpz` sharing, offline signed licenses.
